# フィールドサポート for kintone

入力例と補足説明を項目のそばに表示し、長いフォームの入力・確認を支援する無料プラグインです。

## ダウンロード

[最新版の無料版をダウンロード](https://github.com/youtotto/field-support/releases/latest)

## できること

- 空欄に入力例を表示、項目の補足説明を表示
- 値のコピー、文字数表示、数値欄の電卓
- ルックアップ参照元へのリンク
- 項目、見出し、グループ、テーブルへの移動

利用できる機能は項目の種類によって異なります。

## 導入方法

1. Releasesから `field-support-2.0.9-free-bundle.zip` をダウンロードして展開します。
2. 中の `field-support-2.0.9-free-plugin.zip` は展開せず、kintoneのプラグイン管理画面へ読み込みます。
3. アプリに追加して対象項目と機能を設定し、保存後にアプリを更新します。まず検証用アプリでご確認ください。

詳しい手順は同梱のREADME・利用者向け説明書をご覧ください。

## 対応と制約

PCのレコード追加・編集・詳細画面が対象です。モバイル・一覧内編集・印刷は対象外です。無料版はライセンス確認の通信を行いません。

重要値の固定表示と「もしも試算」はフィールドサポート＋の機能です。無料版・試用版・製品版は同じプラグインIDです。版を入れ替えると同じドメインで利用中の全アプリに反映されます。設定を控え、検証用アプリで確認してから更新してください。

電卓などの入力反映はレコードの保存ではありません。kintoneの保存操作で確定します。
